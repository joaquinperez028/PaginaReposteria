Busco desarrollar un sitioweb donde se pueda leer el codigo de barras de diferentes articulos utilizando la camara del telefono celular, que se identifique este producto a travez de una api que ya almacena los datos y la existencia de estos productos. Tambien se deben poder crear proyectos los cuales van a registrar los productos escaneados, asignandoles un nombre, precio, cantidad, usos, categoria, foto tomada en el momento con la camara del celular o administrada desde los archivos, tiempos de coccion y demas cosas que nos puedan ser utiles para el sitio web
